# Art assets

The game source is wired for these image files:

## Backgrounds
Place these in `assets/backgrounds/`:
- `outside_day.webp`
- `outside_night.webp`
- `inside_day.webp`
- `inside_night.webp`

## Mortimer sprites
Place these in `assets/sprites/`:
- `mortimer_neutral.webp`
- `mortimer_annoyed.webp`
- `mortimer_angry.webp`
- `mortimer_blushing.webp`
- `mortimer_embarrassed.webp`
- `mortimer_emotional.webp`
- `mortimer_smiling.webp`
- `mortimer_in_love.webp`

The HTML/CSS/JS already references these exact paths, so once the art files are added the dating sim will use the changing cabin background behind Mortimer and swap his expression/pose per dialogue scene automatically.
